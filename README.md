# Введение в работу с базами данных

Ядро для учебного домашнего задания по работе с базами данных. Реализовано на Python с использованием библиотеки `psycopg2`.

## Описание проекта
Проект представляет собой скрипт для импорта данных из CSV-файлов в реляционную базу данных PostgreSQL.

### Домашнее задание 18.1: Введение в работу с базами данных
Реализованы следующие этапы:
- **Создание БД**: Локальная база данных `north` в PostgreSQL.
- **Создание таблиц**: Скрипт `create_tables.sql` для создания таблиц `employees`, `customers`, `orders` с определением типов данных и внешних ключей (Foreign Keys).
- **Импорт данных**: Скрипт `main.py` считывает данные из CSV-файлов и выполняет массовую вставку в таблицы БД.
- **Проверка**: Валидация успешного импорта через запросы в pgAdmin.

## Установка и запуск
1. Клонируйте репозиторий или создайте проект:
   git clone <ссылка_на_репозиторий>
   cd homework_18_1
   
2. Активируйте виртуальное окружение и установите зависимости:
   pip install psycopg2-binary
3. Создайте БД north в PostgreSQL и выполните в ней скрипт create_tables.sql.
4. При необходимости измените пароль в файле main.py (функция get_connection).
5. Запустите скрипт импорта:
   python main.py
